##Pong Game
A simple browser‑based Pong game built with HTML, CSS, and JavaScript. 
This project recreates the classic two‑player arcade experience using basic physics, collision detection, and smooth paddle movement.

##Features
Two‑player paddle controls
Ball movement with collision detection
Score tracking
Responsive layout
Lightweight, vanilla JavaScript implementation

##How It Works
The game uses JavaScript to:
Update ball position frame‑by‑frame
Detect collisions with paddles and boundaries
Adjust ball direction based on impact
Listen for keyboard input to move paddles
Render updates using the DOM for smooth gameplay

##Tech Stack
HTML — game structure
CSS — layout and styling
JavaScript — game logic, physics, and input handling

##Project Goals
This project was created to practice:
DOM manipulation
Real‑time game loops
Basic physics simulation
Event listeners and keyboard input
Clean, readable JavaScript structure
